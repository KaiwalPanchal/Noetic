# Twitter — Build in Public

This folder documents the **journey** of building things. It's separate from the topic content pipeline in `{{engine}}/03-pipeline/`.

| Folder | What goes here |
|--------|----------------|
| `journey/` | Dated build-log entries from `/journey`: raw, honest, failures included |
| `drafts/`  | Journey entries turned into threads by `/draft` |
| `ready/`   | Copy-paste text staged by `/ship`. **Posted by hand**; nothing here auto-posts |
| `posted.md` | Ledger of everything published (both pipelines) |

Loop: `/journey` → `/draft <entry>` → `/ship <draft>` → post manually → `/ship <draft> posted <url>`
