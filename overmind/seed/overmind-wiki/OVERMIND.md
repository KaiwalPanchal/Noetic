## Constitution

1. Intent before action: state the goal a task serves before doing it.
2. One source of truth per fact. Link to it instead of copying it.
3. Verified completion only: nothing counts as done until it is checked.
4. Ship over meta-structure: do not reorganize while something is waiting to be published.
5. Private stays private: `wiki/profile/` is never quoted in published material.

## How agents work here

- At session start read this file, then `wiki/profile/operating-contract.md`.
- Propose changes to goals, quests and the XP ledger; the owner confirms.
- Record notable events in `wiki/log/YYYY-MM.md`.
