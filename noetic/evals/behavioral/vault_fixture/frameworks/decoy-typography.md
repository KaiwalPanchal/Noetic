# Framework: Modular Typographic Scales

**Source:** Modular Typographic Scales and Vertical Rhythm in User Interfaces — Jan Tschichold Redux (https://design.vault/modular-scales)  
**Linked Interests:** [[interests#ui-aesthetics]], [[interests#visual-hierarchy]]

**Admission Score:** 5.0/5.0 (Admission Rubric)  
**The Keyboard Test:** Selects font-sizes conforming to modular scale and 8px rhythm.  

---

## 1. Core Idea
Visual hierarchy is established through mathematically proportional type scales and consistent baseline rhythm.

## 2. Core Heuristic & Trigger
- **When in formatting user interface text and typography** → Prioritize **Mathematical modular scale and baseline grid rhythm** over _Ad-hoc custom pixel sizing_ because mathematical proportions create subconscious visual harmony and effortless reading cadence. (Rule: `Enforce font-sizes strictly derived from a fixed 1.333 modular scale snapped to an 8px grid`) [Tier 3] [Tags: ui, typography, design] [Anchor: A robust user interface enforces a strict modular scale—a geometric progression of font sizes derived from a musical or mathematical ratio.]
- **The Core Question / Razor:** "Does this text size belong to the canonical geometric scale?"
- **Governing Invariant:** Visual interface harmony requires geometric typography scales snapped to baseline grids.

## 3. Mental Moves / Procedures
1. Determine base font size (e.g. 16px).
2. Apply 1.333 ratio for headline tiers.
3. Snap line-height to 8px baseline grid.

## 4. Where to Apply
- **Primary Domain:** ui-typography
### Ontology Primitives
- **Modular Scale** (`variable`): A geometric progression of font sizes derived from a fixed mathematical ratio.
- **Vertical Rhythm** (`force`): Alignment of element heights and margins to a 4px or 8px baseline grid.

### Trade-Off Matrix
| Tension Dimension | Recommended Choice | Sacrificed | Gained | Boundary Flip Condition |
| :--- | :--- | :--- | :--- | :--- |
| Visual Sizing | Fixed modular scale progression | Ad-hoc pixel tweaking for individual edge-case labels | Subconscious visual harmony and predictable component rhythm | Monospace code editors and terminal displays where fixed character grid spacing supersedes proportional type |

## 5. Anti-Patterns & Boundaries (When it Breaks)
- **Arbitrary Font Size Salad**: Using 13px, 14px, 15px, 17px, 19px unpredictably across modal dialogs → Interface appears sloppy and jarring to user eyes (Recovery: Normalize typography into a design-system modular token ramp)
