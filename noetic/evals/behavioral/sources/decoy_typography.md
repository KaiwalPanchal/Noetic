# Modular Typographic Scales and Vertical Rhythm in User Interfaces

By Jan Tschichold Redux (2023)

## 1. Principles of Typographic Harmony

Typography is the foundational scaffolding of visual interface design. Text does not merely convey textual tokens; it establishes visual hierarchy, pace, and cognitive flow through optical spacing and typographic contrast.

A robust user interface enforces a strict **modular scale**—a geometric progression of font sizes derived from a musical or mathematical ratio (such as the Perfect Fourth 1.333 or the Golden Ratio 1.618). Arbitrary font sizing (e.g., using 13px, 14px, 15px, 17px ad hoc across different components) destroys interface cohesion.

Furthermore, all typography must adhere to a strict **vertical rhythm**: line-heights and block margins must align to a consistent 4px or 8px baseline grid.

## 2. Directional Heuristic

- **When formatting user interface text and typography** → Prioritize **Mathematical modular scale and baseline grid rhythm** over _Ad-hoc custom pixel sizing_ because mathematical proportions create subconscious visual harmony and effortless reading cadence.
